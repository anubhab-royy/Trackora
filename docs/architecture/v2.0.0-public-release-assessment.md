### New Developer Experience

A new developer can:

```
1. git clone https://github.com/anomalyco/trackora.git
2. cd trackora
3. python -m venv .venv
4. .venv\Scripts\activate
5. pip install -r requirements.txt
6. python -m trackora          # Run the app
7. python -m pytest            # Run tests
8. pyinstaller Trackora.spec   # Build executable
```

All steps are documented in README.md and BUILD.md.
