### Rationale

1. **All CRITICAL and HIGH issues resolved** — RB-1, RB-2, RB-9 (CRITICAL); build version, hidden imports, env loading (HIGH). No release-blocking issues remain.
2. **Full test green** — 356 core tests pass, only pre-existing (non-regression) skip/fail.
3. **Successful production build** — PyInstaller build completes with correct version `2.0.0` and all required hidden imports.
4. **Discovery cross-drive coverage** — All 7 detectors tested; Ubisoft upgraded to registry-based cross-drive support.
5. **MongoDB Atlas path cleared** — `.env` now searchable from `%APPDATA%/Trackora/.env` in production builds. Users configure credentials via Windows system environment or AppData `.env` file.
6. **Charts engineering verified** — `setMaximumHeight(300)` confirmed in all 3 chart widgets.
7. **Dashboard verified** — Controller + widget error handling works correctly, no crash after RB-9.
