# Trackora v2.0.1 Development Log — July 6, 2026

## Overview
Completed the first phase of Trackora v2.0.1 engineering focusing on Silent Startup (`--silent`) and robust Update Center components. Addressed the version synchronization pipeline, manual rate-limiting bypass logic, PyQt6 desktop navigation type errors, and resolved API connection settings.

---

## Completed Engineering Work
* **Silent Startup (T-201)**: Implemented startup argument parsing allowing execution to stay minimized to the tray.
* **Background Check Thread (T-210)**: Threaded update queries (`QThread`) to ensure GUI is completely non-blocking.
* **Version Comparisons (T-212)**: Implemented strict semver comparisons.
* **Direct Browser Download Trigger (T-215)**: Integrated direct installer `.exe` routing from the update dialog download button.
* **Manual Bypass Logic**: Manual checks override the caching cooldown to execute a live query immediately.
* **Version Management Automation**: Created `scripts/bump_version.py` to synchronize version attributes to `version_info.txt` and `installer/version.iss` at build time.

---

## Problems Found & Root Causes
1. **Stale Binary Versioning (2.0.0)**: Executables compiled with PyInstaller were embedding stale resource metadata because `version_info.txt` was hardcoded.
2. **GitHub API 404 Failure**: The update checker queries returned `HTTP Error 404: Not Found` from the GitHub API. This was caused by hardcoded references to a mock repository `"anomalyco/trackora"` instead of `"anubhab-royy/Trackora"`.
3. **QDesktopServices TypeError Crash**: Clicking the "Download" button inside the update dialog did nothing. The root cause was that `QDesktopServices.openUrl()` expects a `QUrl` object, but was passed a raw Python string.

---

## Solutions Implemented
1. Created `scripts/bump_version.py` to auto-propagate version attributes from `trackora/__init__.py` (source of truth) into build spec files and Inno Setup definitions. Added `test_version_consistency.py` to assert alignment.
2. Corrected all repository endpoint configurations to `"anubhab-royy/Trackora"`.
3. Wrapped URLs in `QUrl` before calling `QDesktopServices.openUrl()`.

---

## Architecture Decisions
* **Dynamic Spec Parsing**: Configured `Trackora.spec` to dynamically extract the current version block by parsing `trackora/__init__.py` directly rather than executing imports (which could trigger side effects at compilation time).
* **Direct Setup Download Preference**: Configured the "Download" button to direct browser execution directly to the `.exe` setup file if present, falling back to the release webpage when absent.
